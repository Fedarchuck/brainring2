# Brain Ring

Простое веб-приложение для викторин и мероприятий, где важно, кто первый нажал на кнопку.

## Описание

Brain Ring - это система для мероприятий, где участники соревнуются в скорости нажатия кнопки. Первый нажавший выигрывает, остальные временно блокируются, после чего кнопки автоматически разблокируются через 1 секунду.

## Установка и запуск

### Требования
- Node.js (версия 14 или выше)
- npm

### Шаги установки

1. Установите зависимости:
```bash
cd server
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

## Использование

1. **Ведущий:**
   - Открывает сайт
   - Нажимает "Создать комнату"
   - Получает 6-значный код комнаты
   - Показывает код или QR участникам

2. **Участники:**
   - Вводят код комнаты
   - Вводят свое имя
   - Видят кнопку "ЖМИ"
   - Первый нажавший выигрывает
   - Остальные временно блокируются
   - Через ~1 секунду все автоматически разблокируется

## Технологии

- **Backend:** Node.js + Express + Socket.IO
- **Frontend:** Vanilla JavaScript, HTML, CSS
- **Real-time:** WebSocket (Socket.IO)

## Порт

По умолчанию сервер запускается на порту 3000. Для изменения порта установите переменную окружения `PORT`:

```bash
PORT=8080 npm start
```
