# Brain Ring

Простое веб-приложение для викторин и мероприятий, где важно, кто первый нажал на кнопку.

## Описание

Brain Ring - это система для мероприятий, где участники соревнуются в скорости нажатия кнопки. Первый нажавший выигрывает, остальные временно блокируются, после чего кнопки автоматически разблокируются через 3 секунды.

## Деплой и локальный запуск

Проект состоит из двух независимых частей:
- `public/` — статический frontend для Vercel или Netlify;
- `server/` — Node.js Socket.IO backend для Render.

### Backend

Разверните папку `server/` отдельным Web Service на Render:
```bash
cd server
npm install
```

```bash
npm start
```

Укажите переменную окружения `CLIENT_ORIGIN` с URL frontend, например:
```bash
CLIENT_ORIGIN=https://your-app.vercel.app
```

### Frontend

Один раз укажите URL Render-сервиса в `productionBackendUrl` файла `public/js/config.js`. На `localhost` frontend автоматически подключается к `http://localhost:3000`, поэтому менять настройку при локальном запуске не нужно.
Подробные инструкции находятся в `public/README.md` и `server/README.md`.

## Использование

1. **Ведущий:**
   - Открывает сайт
   - Нажимает "Создать комнату"
   - Получает 6-значный код комнаты
   - Показывает код или QR участникам

2. **Участники:**
   - Вводят код комнаты
   - Вводят свое имя
   - Видят кнопку "ЖМИ"
   - Первый нажавший выигрывает
   - Остальные временно блокируются
   - Через ~1 секунду все автоматически разблокируется

## Технологии

- **Backend:** Node.js + Express + Socket.IO
- **Frontend:** Vanilla JavaScript, HTML, CSS
- **Real-time:** WebSocket (Socket.IO)

## Порт

По умолчанию сервер запускается на порту 3000. Для изменения порта установите переменную окружения `PORT`:

```bash
PORT=8080 npm start
```
